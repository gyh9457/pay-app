# 04 历史汇总与启用日衔接

Status: done
Blocked by: 03

提供离线录入和保存历史月度汇总、启用前累计与截止日期的入口，在月、年账单区分历史汇总和逐笔记录。

- [x] 用示例金额覆盖启用前一天、启用当天和月末。验证历史累计只计一次。
- [x] 验证历史汇总计入对应月与全年，周账单、每日明细、分类小计仅包含逐笔支出。
- [x] 重复保存同一历史月份或期初设置时不会重复累计，重启后仍可读取。

## 验证与审查

Codex 于 2026-11-24 复核 Xcode 15.4、iPhone 15 / iOS 17.5 模拟器结果，116 项单元、27 项 UI 测试通过，模拟器 Release 产物已核对。

- UTC+08、UTC+09、UTC 的示例账均排除累计截止日 11 月 15 日的 1.00，计入 11 月 16 日的 2.00 及 11 月 30 日的 3.00。10 月历史 40.00、11 月期初 50.00 各计一次，11 月合计 55.00，全年合计 95.00。启用周和对应一级分类均为 2.00，月逐笔只显示 2.00 和 3.00。
- 旧副本待清理时追加支出，重启并切换时区后两笔各出现一次，逐笔日期与金额仍匹配。定向测试在故意改错其中一笔显示日期时失败，恢复后通过。
