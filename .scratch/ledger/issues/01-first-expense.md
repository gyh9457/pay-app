# 01 建立工程并贯通第一笔支出

Status: done
Blocked by: None

创建供 Xcode 15.4 打开的可运行工程、共享 scheme 和测试入口。贯通首页进入记账、输入正数金额、使用一个示例分类、以今天和现金为默认值保存、返回首页更新金额。关闭并重新打开 App 后原记录仍可见。

- [x] iPhone 15 / iOS 17.5 模拟器可构建和启动，记录构建与测试命令。
- [x] 示例支出可保存，重启后仍可读取。金额精确到分，拒绝无效或非正数输入。
- [x] 账本只保存在当前设备，排除系统备份。

## 验证与审查

Codex 于 2026-11-22 在 Xcode 15.4、iPhone 15 / iOS 17.5 模拟器用示例账本复验，66 项单元与 7 项 UI 测试通过，模拟器 Release 构建通过。

- 输入、保存返回、重启读回及周一与半开区间逐笔汇总均通过。
- 迁移验证覆盖首次迁移、完整副本和合并迁移。启动读取与已验证快照不一致时暂停记账并保留原字节，恢复后每笔只读回一次。已观察到正式路径后仍尝试设置备份排除标记，即使后续读取报缺失。
