# 02 双列分类选择与分类维护

Status: done
Blocked by: 01

在记账表单提供底部双列滚轮，一级分类改变时刷新对应子类，表单同步显示选择。支持新增和改名一级分类及子类，重启后保留。

- [x] 用示例分类演示滚轮联动、选择同步与保存返回。
- [x] 改名后旧账保留日期和金额、显示新名称。验证新增、改名与重启读取。

## 验证与审查

在 iPhone 15 / iOS 17.5 模拟器用示例账本验证，Codex 复核 80 项单元与 11 项 UI 测试通过，以及模拟器 Release 产物。

- 双列滚轮同步选中项，点「完成」后保留输入，保存回首页。无子类的大类可保存，新增首个子类后返回表单会选中。
- 两级分类可新增、改名并重启读回。改名保留分类标识、旧记录金额和日期。分类保存失败保留此前数据，备份排除检查通过。
- 内置分类的完整名称和顺序见 [06](06-recorded-categories.md)。

复跑命令和待验范围见 [05 集成验证](05-integration.md)。
