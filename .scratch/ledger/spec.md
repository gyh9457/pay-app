# 随手记首版

[原始需求](../../原始需求.md)是功能约定。首版在本地离线记录现金支出，支持分类维护、周月年账单，以及旧账按月汇总后的衔接。账本保存在当前设备，开发使用示例金额。

## 要交付的流程

1. 从首页点「记一笔」，输入正数金额，通过两列联动滚轮选择分类和子类，保存后返回首页并更新摘要。日期默认今天，账户固定现金。
2. 新增和改名两级分类。历史支出按同一分类标识显示新名称。
3. 周账单按周一至周日汇总一级分类，可展开逐笔支出。月账单和年账单在原页独立展开月份及每日逐笔记录。
4. 本地录入历史月度总额和启用日前累计。两者计入对应月和年，逐笔统计与分类小计只使用明细。启用日边界核对见原始需求。

## 实现和验收约定

- SwiftUI 工程使用本机 Xcode 15.4 可打开的格式，提供可运行的共享 scheme。首版按 iOS 17.5 模拟器验证，并使用系统框架实现本地持久化。操作和统计均可离线完成。
- 用精确金额表示和日历区间计算验证汇总。用公开的账本操作测试保存、重启读取、分类改名及历史边界。用模拟器验证从首页到记账和账单的主要路径。
- 内置分类和顺序见已从录屏转录的[分类对照表](issues/06-recorded-categories.md)。原始录屏已由用户删除，录屏回看和 iOS 26.6 真机待验项见[集成验证](issues/05-integration.md)。真实历史数据由用户持有，模拟器用示例值验证。
- 设计沿用浅色列表、顶部风景与摘要、橙色记账按钮和绿色支出金额。首页摘要与账单结果应由同一套统计逻辑计算。
